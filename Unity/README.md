# Motorcity Roll Patrol (Unity 6 LTS, URP, Android)

Abrir esta carpeta (`Unity/`) con Unity Hub (6000.0.x). Al abrir, `ProjectBootstrap`
aplica la configuración de rendimiento/Android (menú `Tools > Motorcity Roll Patrol`).

Terreno: colocar un `.raw` 16-bit en `Datos_Topograficos/Heightmaps` (extensión `.bytes`),
crear `TerrainImportSettings` en `Datos_Topograficos/Config` y asignarlo a un `TerrainImporter`.
